# KIXIONLINE

Aplicação inicial em React + TanStack Start, com identidade visual verde e branca.

## Execução
1. Instale Node.js LTS.
2. Execute `npm install`.
3. Execute `npm run dev`.
4. Para validar a compilação, execute `npm run build`.

## Estado
A interface actual é uma demonstração. Os botões de entrada e adesão ainda não estão ligados a autenticação, grupos ou pagamentos. Não recebe nem confirma dinheiro real.
